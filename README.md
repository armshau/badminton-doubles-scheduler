# 🏸 8 人雙打單唱 14 場賽程產生器與驗證系統 (Badminton Doubles Tournament Scheduler)

一個純前端 (Pure Frontend) 靜態網頁應用程式，專為 8 人雙打（雙打單唱）羽球與各類球類運動設計。自動求解並極大化「連續上場 2 場人次（達 **23 人次**）」且完全滿足所有對戰與組合約束條件。

👉 **線上免安裝使用**：[https://armshau.github.io/badminton-doubles-scheduler/](https://armshau.github.io/badminton-doubles-scheduler/)

---

## 🌟 核心功能與特色

- 👥 **自訂 8 人姓名**：輸入框動態連動，修改姓名後全頁賽程與圖表即時更新。
- 🛡️ **七大規則合規儀表板**：自動驗證每項約束條件（隊友搭配、對手次數、上場場次、連續場次限制）。
- 📊 **選手對照與「連2」矩陣**：清晰標示每一場每人的狀態與黃色 `連2` 高亮標籤。
- 🤝 **隊友與對手檢驗矩陣**：展示 28 種隊友組合（全為 1 次）與 28 種對手組合（全為 2 次）。
- 📋 **一鍵複製 (LINE 格式)**：一鍵複製排版好的對戰表文字，方便傳送到 LINE 或 Messenger 群組。
- 📥 **CSV 數據匯出**：支援一鍵下載 CSV 檔案供 Excel 開啟。
- 🖨️ **列印專用樣式 (Print CSS)**：列印時自動隱藏控制按鈕，呈現簡潔純白紙本表格。

## 📐 數學與約束條件驗證

| 規則與約束條件 | 數學與演算法驗證結果 | 狀態 |
| :--- | :--- | :---: |
| **1. 雙打 2vs2 形式** | 每場 4 人（隊伍 A 兩人 vs 隊伍 B 兩人） | `✓ 通過` |
| **2. 每人與其餘 7 人各組隊 1 次** | 14 場 $\times$ 2 隊 = 28 隊，恰好涵蓋 $\binom{8}{2} = 28$ 種隊友對組合 | `✓ 通過` |
| **3. 每人與其餘 7 人各當對手 2 次** | 14 場 $\times$ 4 對手對 = 56 對手次數，涵蓋 28 種組合各 2 次 | `✓ 通過` |
| **4. 每人剛好上場 7 場** | 14 場 $\times$ 4 人次 = 56 人次，$56 / 8 = 7$ 場/人（上場 7 場、休息 7 場） | `✓ 通過` |
| **5. 共 14 場賽程** | 總場次精確為 14 場 | `✓ 通過` |
| **6. 絕不連續上場 3 場** | 最長連續上場上限為 2 場，完全無任何連續 3 場 | `✓ 通過` |
| **7. 最大化「連續上場 2 場」總人次** | 理論與實務全域極大值為 **23 人次** (7 人各 3 次連2，1 人 2 次連2) | `★ 全域最佳` |
